# 公司销售部门内部抽奖系统

## 项目概述
这是一个基于PHP+MySQL的内部抽奖系统，专为公司销售部门设计，用于管理和进行内部抽奖活动。系统支持多项目管理、用户权限控制、抽奖次数分配等功能。

## 功能特点
- **项目管理**：创建、编辑、删除抽奖项目
- **奖品管理**：设置奖品名称、数量、中奖概率
- **用户管理**：基于IP地址的用户识别和绑定
- **次数分配**：支持单人/批量分配、负数扣减、刷新与IP展示
- **权限控制**：控制用户在特定项目中的可见性
- **抽奖动画**：炫酷的抽奖动画效果
- **实时统计**：显示用户个人信息和抽奖统计
- **历史记录**：完整的抽奖历史查询、搜索与筛选
- **响应式设计**：支持PC和移动端访问

## 技术栈
- **后端**：PHP 7.4+
- **数据库**：MySQL 5.7+
- **前端**：HTML5/CSS3/JavaScript
- **样式框架**：Tailwind CSS
- **图标库**：Font Awesome
- **架构**：MVC模式，PDO数据库操作

## 系统要求
- PHP 7.4 或更高版本
- MySQL 5.7 或更高版本
- Web服务器（Apache/Nginx）
- 支持PDO扩展

## 安装指南

### 1. 环境准备
确保您的服务器环境满足系统要求。

### 2. 下载代码
将项目文件放置到Web服务器目录中。

### 3. 数据库配置
1. 创建MySQL数据库
2. 导入数据库文件：
   ```sql
   mysql -u username -p database_name < database.sql
   ```
3. 修改 `config.php` 文件中的数据库配置：
   ```php
   define('DB_HOST', 'localhost');     // 数据库主机
   define('DB_USER', 'your_username'); // 数据库用户名
   define('DB_PASS', 'your_password'); // 数据库密码
   define('DB_NAME', 'lottery_system'); // 数据库名称
   ```

### 4. 文件权限
确保 `uploads/` 目录具有写入权限：
```bash
chmod 755 uploads/
```

### 5. 访问系统
通过浏览器访问系统首页，首次访问会要求注册用户。

## 页面说明

### 用户端页面
- **首页 (index.php)**：用户抽奖主界面，显示个人信息、项目选择、奖品列表和抽奖功能
- **注册页面 (register.php)**：新用户注册界面，基于IP地址绑定
- **历史记录 (history.php)**：查看个人抽奖历史，支持筛选和分页

### 管理端页面
- **管理后台 (admin.php)**：系统管理界面，包含以下功能模块：
  - 项目管理：创建、编辑、删除抽奖项目
  - 奖品管理：设置奖品信息、中奖概率与快速调整
  - 用户管理：管理注册用户信息
  - 次数分配：为用户分配抽奖次数、支持批量与负数调整

## 使用说明

### 管理员操作流程
1. 访问管理后台 (`admin.php`)
2. 创建抽奖项目
3. 为项目添加奖品并设置中奖概率
4. 为用户分配抽奖次数
5. 用户即可开始抽奖

### 用户操作流程
1. 首次访问自动跳转到注册页面
2. 输入真实姓名完成注册
3. 选择可参与的抽奖项目
4. 点击抽奖按钮进行抽奖
5. 查看抽奖结果和历史记录

- **prizes**：奖品信息表

- 抽奖次数限制，防止恶意刷奖

## 故障排除

### 常见问题
1. **数据库连接失败**：检查 `config.php` 中的数据库配置
2. **页面显示异常**：确保PHP版本符合要求
3. **抽奖失败**：检查奖品库存和用户剩余次数
4. **权限错误**：确保 `uploads/` 目录有写入权限

### 调试模式
在 `config.php` 中启用错误显示：
```php

error_reporting(E_ALL);
```

## 版本历史

### 后台报销工作台与本地预览
- 用户列表提供带文字的“查看详情”入口；详情按项目次数、抽奖报销、分配日志分区，统计全部抽奖历史，记录列表最多展示最近50条。
- 用户详情内支持直接快速报销，成功后同步刷新用户统计和当前分区；支持加载失败重试、Esc关闭和弹窗内键盘焦点循环。
- 后台默认打开抽奖记录，展示待报销、已报销和累计记录统计；支持姓名、项目、奖品、记录编号搜索及报销状态筛选。
- 快速报销成功后自动刷新当前列表和统计；窄屏使用卡片布局，让报销按钮无需横向滚动即可操作。
- 后台样式、图标使用项目内资源。共享记录查询位于 `admin_records.php`，页面样式位于 `assets/css/admin.css`。
- 可使用 `python tools/start_preview.py --php /path/to/php.exe --mysqld /path/to/mysqld.exe` 启动 Windows 本地预览。脚本输出访问地址、临时目录和两个服务的 PID；测试站点与数据库独立，包含示例中奖记录，默认管理员密码为 `admin123`。服务仅监听本机，启动命令结束后继续运行，方便手动测试。
- 预览是启动时的代码副本；修改代码后需同步副本或重新启动预览。临时目录中的 `preview.json` 记录本次服务信息。

### 报销流程优化
- 新增报销正确保存附件；支持 JPG、PNG、PDF，最大 10MB，按文件实际类型校验。PHP 的 `upload_max_filesize` 和 `post_max_size` 也需允许对应大小。
- 待审批或已拒绝单据仍需申请满两天才能编辑；保存修改后回到待审批，清空旧审批信息。
- 只有待审批记录可以通过或拒绝；已通过、已核销记录不能删除，避免删除后重复核销。
- 新增、修改、审批、快速报销均保存操作历史，与业务数据在同一事务中提交；失败回滚并清理本次新附件。
- 快速报销从中奖记录获取真实项目，并锁定记录防止跨管理员重复报销；修复 `#1` 误匹配 `#10`，兼容已有报销事由格式，无需修改数据库结构。
- 报销写操作校验会话令牌，提交时禁用按钮；历史详情安全显示引号和特殊字符。报销统计统一按当前筛选条件计算。
- 保留普通新增可选择“已通过”、快速报销允许零元的现有规则；自动补齐对应审批人及审批时间。

Windows 隔离集成测试（需要 Python、PHP PDO MySQL/fileinfo、MySQL 5.7，Node 可用于额外检查页面脚本）：
```bash
python tests/expense_integration.py --php /path/to/php.exe --mysqld /path/to/mysqld.exe
```
测试自行创建临时 MySQL 数据目录和独立站点，运行新增附件、拒绝后修改提交、审批、重复与并发核销、校验失败及事务回滚用例；结束时清理临时进程和文件，不读取业务数据库凭据、不修改业务数据。

### 核心流程优化
- 首页通过一次关联查询加载用户可见项目及剩余次数，默认选择第一个可见项目。
- 抽奖事务锁定用户次数与可用奖品，并通过条件更新防止次数和库存扣成负数；要求相关表使用 InnoDB。
- 保留“没有中奖”及库存达到 999999 时不扣减的规则，使用 `random_int` 生成随机数。
- 校验抽奖项目参数，数据库事务异常只向客户端返回通用提示；奖品名称通过纯文本显示。
- 历史记录以时间和记录 ID 排序，确保相同时间记录的分页顺序稳定。

运行隔离回归测试（不会连接业务数据库）：
```bash
php tests/lottery_regression.php
```
测试覆盖扣减、耗尽、回滚、数据库异常和特殊奖品规则。数据库替身只能验证事务调用和业务分支，实际行锁效果需在测试 MySQL 中并发验证：同一用户仅剩一次机会时并发抽奖只能成功一次；不同用户竞争最后一件奖品时只能产生一条对应中奖记录。
