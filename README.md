# 公司销售部门内部抽奖系统

## 项目概述
这是一个基于PHP+MySQL的内部抽奖系统，专为公司销售部门设计，用于管理和进行内部抽奖活动。系统支持多项目管理、用户权限控制、抽奖次数分配等功能。

## 功能特点
- **项目管理**：创建、编辑、删除抽奖项目
- **奖品管理**：设置奖品名称、数量、中奖概率
- **用户管理**：基于IP地址的用户识别和绑定
- **次数分配**：为不同用户在不同项目中分配抽奖次数
- **权限控制**：控制用户在特定项目中的可见性
- **抽奖动画**：炫酷的抽奖动画效果
- **实时统计**：显示用户个人信息和抽奖统计
- **历史记录**：完整的抽奖历史查询和筛选
- **响应式设计**：支持PC和移动端访问

## 技术栈
- **后端**：PHP 7.4+
- **数据库**：MySQL 5.7+
- **前端**：HTML5/CSS3/JavaScript
- **样式框架**：Tailwind CSS
- **图标库**：Font Awesome
- **架构**：MVC模式，PDO数据库操作

## 系统要求
- PHP 7.4 或更高版本
- MySQL 5.7 或更高版本
- Web服务器（Apache/Nginx）
- 支持PDO扩展

## 安装指南

### 1. 环境准备
确保您的服务器环境满足系统要求。

### 2. 下载代码
将项目文件放置到Web服务器目录中。

### 3. 数据库配置
1. 创建MySQL数据库
2. 导入数据库文件：
   ```sql
   mysql -u username -p database_name < database.sql
   ```
3. 修改 `config.php` 文件中的数据库配置：
   ```php
   define('DB_HOST', 'localhost');     // 数据库主机
   define('DB_USER', 'your_username'); // 数据库用户名
   define('DB_PASS', 'your_password'); // 数据库密码
   define('DB_NAME', 'lottery_system'); // 数据库名称
   ```

### 4. 文件权限
确保 `uploads/` 目录具有写入权限：
```bash
chmod 755 uploads/
```

### 5. 访问系统
通过浏览器访问系统首页，首次访问会要求注册用户。

```

├── register.php       # 用户注册页面

├── history.php        # 抽奖历史页面
```

## 页面说明

### 用户端页面
- **首页 (index.php)**：用户抽奖主界面，显示个人信息、项目选择、奖品列表和抽奖功能
- **注册页面 (register.php)**：新用户注册界面，基于IP地址绑定
- **历史记录 (history.php)**：查看个人抽奖历史，支持筛选和分页

### 管理端页面
- **管理后台 (admin.php)**：系统管理界面，包含以下功能模块：
  - 项目管理：创建、编辑、删除抽奖项目
  - 奖品管理：设置奖品信息和中奖概率
  - 用户管理：管理注册用户信息
  - 次数分配：为用户分配抽奖次数和权限

## 使用说明

### 管理员操作流程
1. 访问管理后台 (`admin.php`)
2. 创建抽奖项目
3. 为项目添加奖品并设置中奖概率
4. 为用户分配抽奖次数
5. 用户即可开始抽奖

### 用户操作流程
1. 首次访问自动跳转到注册页面
2. 输入真实姓名完成注册
3. 选择可参与的抽奖项目
4. 点击抽奖按钮进行抽奖
5. 查看抽奖结果和历史记录

## 数据库设计

### 主要数据表
- **users**：用户信息表
- **projects**：抽奖项目表
- **prizes**：奖品信息表
- **user_project_times**：用户项目抽奖次数表
- **lottery_records**：抽奖记录表

### 关键特性
- 支持外键约束，保证数据完整性
- 使用事务处理，确保抽奖过程的原子性
- 基于概率的公平抽奖算法

## 安全特性
- SQL注入防护（使用PDO预处理语句）
- XSS攻击防护（输出转义）
- IP地址绑定，防止重复注册
- 抽奖次数限制，防止恶意刷奖

## 故障排除

### 常见问题
1. **数据库连接失败**：检查 `config.php` 中的数据库配置
2. **页面显示异常**：确保PHP版本符合要求
3. **抽奖失败**：检查奖品库存和用户剩余次数
4. **权限错误**：确保 `uploads/` 目录有写入权限

### 调试模式
在 `config.php` 中启用错误显示：
```php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```
